# Worlds with ores (Forge 1.20.1)

Port of Worlds with ores to Minecraft Forge 1.20.1.

## Features
- 7 ore dimensions with portal progression
- Custom chest, lava-obsidian gear, recipe book
- Soft industrial ore gen + machine recipes (Create, Mekanism, IE, Thermal, AE2, Extreme Reactors)
- Works without those mods installed

## Build
`.\gradlew.bat build`

Requires JDK 17.

## Features

- 7 vanilla-style **single-ore portal dimensions**
- Optional **soft industrial worlds** (Create, Mekanism, Immersive Engineering, Thermal, Extreme Reactors, AE2)
- **Lava Obsidian** tools & armor
- In-game **recipe book** with 3D portal previews
- **Portal Flux** FE reactor (hologram, coil tiers, modules) — *work in progress*

## Install

1. Forge **1.20.1**
2. Drop `worlds_with_ores-*-1.20.1.jar` into `mods`
3. Latest release: https://github.com/milioners/Worlds-with-ores/releases

## Build

Requires **JDK 17**.

```bat
.\gradlew.bat build
```

JAR output: `build/libs/`
